A program that writes exactly one letter to `/output/entry.txt` — the letter that stands for the word describing the day.

Our letter is **K**, for **Karaoke**: a day of friends passing one microphone around, every chorus sung off-key at full volume, nobody reaching the high notes, everybody loving it anyway.

## Run it

```sh
node main.ts
```
